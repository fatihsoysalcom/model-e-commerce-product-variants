# Model E-commerce Product Variants

This example demonstrates how to model product variants for e-commerce, using a 'kurti' as an example. It generates unique SKUs and manages stock for each combination of attributes like color, size, fabric, and pattern, highlighting that each variant is a distinct product. The code illustrates how to define product attributes, generate all possible variants, and perform operations like stock updates on specific variants.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`
